## 3. README do Projeto — Aplicativo de Delivery

# Aplicativo de Delivery

### Sobre o projeto

Projeto acadêmico desenvolvido na disciplina Design Profissional, do curso de Bacharelado em Engenharia de Software.

O objetivo foi criar a proposta visual de um aplicativo de delivery, proporcionando uma experiência simples, intuitiva e organizada desde o login até a realização do pedido e pagamento.

Minha atuação foi concentrada na criação da interface visual e prototipação, sem implementação de back-end ou processamento real de pagamentos.

### Objetivo

Desenvolver uma interface de delivery com navegação clara e boa experiência para o usuário.

Foram criadas as principais telas:

* Login;
* Tela principal;
* Pedidos;
* Detalhes do pedido;
* Pagamento.

### Ferramentas utilizadas

* Figma — criação das interfaces e prototipação;
* Adobe Illustrator — criação e edição de elementos gráficos.

### Conceitos aplicados

UI/UX Design, prototipação, hierarquia visual, organização de informações, usabilidade, navegação e experiência do usuário.

### Aprendizados

O projeto permitiu compreender melhor a relação entre design, experiência do usuário e desenvolvimento de software. Foram desenvolvidas habilidades de planejamento de interfaces, organização de informações, criação de jornadas de navegação e prototipação.

A experiência também possibilitou relacionar meus conhecimentos anteriores em Design com minha atual formação em Engenharia de Software.

### Próximos passos

A próxima etapa será transformar o protótipo em uma aplicação funcional, implementando o front-end, navegação entre telas, API, banco de dados, autenticação de usuários, gerenciamento de pedidos e pagamentos em ambiente de testes.
